使用方式（你自己怎么用这份表）
术语 = 文献里可检索的抓手。
研究问题模板 = 把术语换成你的对象（任意「被谈论的实体 / 互动平台 / 话语类型」）。
迁移提示 = 强制你做类比，避免只会做一种数据。
1. 指称、指示与实体建构（reference & deixis）
术语（中/英）	核心含义（极简）	可构思的问题（模板）	举一反三
指示语 / Deixis
语言把话语锚定在「谁—何时—何地—相对谁」的坐标系
语料里中心视角是谁？失败/成功叙事是否切换指示中心？
医疗对话里「这个病/我这病」；新闻里「我国/该国」
人称指示 / Person deixis
我/你/他/我们标记互动角色与社会距离
「我们」包容谁、排斥谁？第二人称是召唤还是攻击？
品牌广告「我们」；抗议口号「你们」
社会指示 / Social deixis
敬语、称呼、头衔标记等级与关系
称呼选择是否随话题风险变化（从尊称到嘲讽）？
职场邮件；直播打赏话术
参照物确立 / Referent accessibility
用代词/专名/描述语取决于听者心里「多容易提取」
同一实体为何有时全名、有时代词、有时绰号化 NP？
政治人物从「总统」到「某人」
指称词形 / Referential form
全名 vs 代词 vs 描述语不仅是省略，更是立场与管理
指称升级/降级是否伴随道德化（从它→畜生；从它→宝贝）？
动物保护话语；AI 人格讨论
共指 / Coreference
多个表面形式指向同一 discourse entity
评论链里「它/他」到底锚谁？是否故意滑动锚点完成反驳？
法庭交叉询问；学术撕稿
实体网格 / Ontology in talk
话语把对象放进「人/物/机构/自然力」等本体槽
语料把对象人化/物化/宠物化的系统性条件是什么？
公司法人；国家拟人；病毒拟人
2. 范畴、身份与成员资格（categorization & identity-in-interaction）
术语	核心含义	可构思的问题	举一反三
成员归类装置 / Membership Categorization Device (MCD)
用少量范畴推出大量道德推论（「他是那种人」）
哪些范畴对被反复并置（例如职业×性别×地域）？
交通事故报道；校园霸凌叙事
范畴推断 / Category-bound activities
某些行为被文化绑定为某类人的「典型」
哪种行为描述用来定罪式归类？
「理性消费者」vs「韭菜」
身份工作 / Identity work
互动中临时建构「我是谁」
说话人如何在同一线程里换身份（路人→专家→受害者）？
问诊；维权帖
立足点 / Footing
Goffman：说话人对自身角色的呈现与切换
同帖是否出现框架切换（科普 footing → 玩梗 footing）？
老师上课开玩笑；新闻反转
框架 / Frame
组织理解与推理的「这是什么类互动」
争论是事实框架还是道德框架？框架冲突点在哪？
气候争论；教育内卷讨论
3. 立场、评价与主观性（stance, evaluation, subjectivity）
术语	核心含义	可构思的问题	举一反三
立场采纳 / Stance-taking
对对象表达态度并对齐/不对齐某群体
立场是显式评价还是通过引用/复述间接完成？
乐评；体育解说
立场三角 / Stance triangle (Du Bois)
评价对象—评价—对齐他人
对齐对象常常是**@用户还是想象受众**？
饭圈控评；学术引用政治
认识立场 / Epistemic stance
对「知道多少、是否确定」的标记
争议是否体现认识权威争夺（显然/据说/我不懂但你更不懂）？
科普辟谣；财经预测
证据立场 / Evidentiality
信息来源（亲见、听说、推断）
高风险断言靠什么证据策略支撑？
法庭证言；游记
情感 / Affect
情绪表达（常带身体化隐喻）
情绪词是真诚还是表演性情感（梗化）？
直播；悼词政治
判断 Judgment（Appraisal）
对人的品格行为评价（可靠/丢人）
道德攻击主要落在判断还是鉴赏？
公众人物的「人品叙事」
鉴赏 Appreciation
对事物/文本价值评价（美/糙/厉害）
「厉害」是在夸技术还是夸国族/公司？
设计评论；电影打分
介入 Engagement（Appraisal）
承认多声、引述、否认、反预期
反驳是直接否认还是借声反驳（有人说…但其实）？
论文讨论；政策解读
级差 Graduation
强化/弱化（很/有点/简直）
级差是否用于道德加码或风险淡化？
公关稿；恐吓式营销
主观性 / Subjectivity
语言标记「谁的观点」
主观标记密度与冲突强度相关吗？
回忆录；证词
互主观性 / Intersubjectivity
互动中协商「我们知道什么」
高赞回复是否在重塑共同基础？
科普评论区共识形成
4. 对话性、声音与互文（dialogism & intertextuality）
术语	核心含义	可构思的问题	举一反三
对话性 / Dialogism (Bakhtin)
话语总是回应他者、承载他声
文本里是否存在隐藏对话者（即便未 @）？
广告「别再…」
异质语 / Heteroglossia
多种社会方言/声音并存
一条话语是否拼接多个语域完成讽刺？
政论段子；学术 meme
互文性 / Intertextuality
引用、暗示、模版、梗
立场是否靠梗的索引完成（懂的人才对齐）？
短视频弹幕；粉圈缩写
复调 / Polyphony
多个声音不合并为单一作者声
引用他人原话时是否扭曲声调？
采访剪辑争议
声音化 / Voicing
模仿某种社会人格来说话
玩梗是否在扮演某类「典型网友」？
方言配音；模仿领导
5. 互动结构、面子与（不）礼貌（interaction & relational work）
术语	核心含义	可构思的问题	举一反三
相邻对 / Adjacency pair
问-答、邀请-接受/拒绝等配对
异步评论如何延迟完成第二配对部分？
邮件；工单系统
偏好组织 / Preference organization
附和 vs 反驳的不对称标记（更拐弯）
「不喜欢」是否更常间接（幽默/反问）？
家庭群；评审意见
修正 / Repair
误解纠正、澄清
追问评论是在修复理解还是在攻击面子？
客服对话
话轮 / Turn-taking
轮流发言规则（平台会改写）
平台机制（排序、折叠）如何改变话轮可见性？
直播连麦；推特线程
面子 / Face (Brown & Levinson)
想要的积极形象与社会许可的自我形象
反驳如何保面或撕面？
学术推特；职场群
礼貌策略 / Politeness strategies
正面礼貌、负面礼貌、直言
高风险话题是否出现过度礼貌或假装礼貌的攻击？
跨文化邮件
不礼貌 / Impoliteness
故意威胁面子
「阴阳怪气」属于哪种不礼貌实现？
电竞对线
缓和 / Mitigation
弱化断言强度以降风险
争议中缓和是真诚协商还是伪装中立？
外交辞令
强化 / Intensification
加码以动员
强化手段是词汇级还是重复/标点/表情级？
动员式口号
6. 预设、含义与论证移动（meaning beyond literal content）
术语	核心含义	可构思的问题	举一反三
预设 / Presupposition
话面之下当作「已成立背景」
争论是否在争预设而非争断言（先把对方钉在某种前提）？
性别议题；教育公平
含义 / Implicature (Grice)
合作原则推导的言外之意
反讽如何靠违反质量/方式准则传达立场？
影评；政治漫画配文
元语用 / Metapragmatics
对「怎么说/在做什么」的评论
是否出现「别杠」「你阅读理解」这类框架战？
论坛治理话语
元话语 / Metadiscourse
组织论证与读者引导
长篇评论如何标记「我先说结论/我分三点」？
知乎体；小红书教程体
7. 论证、立场动力学与争议（argument & controversy）
术语	核心含义	可构思的问题	举一反三
论证挖掘 / Argument mining
自动/半自动抽 claim—premise—support/attack
支持关系更多靠事实还是靠道德判断？
政策评论区；产品评测
立场分类 / Stance classification
对命题的 favor/neutral/against（任务定义多变）
任务是对事件还是对上一话轮立场？定义一改结果就变
多语言 stance 评测
对话分歧 / Conversational divergence
后续话轮引入新命题轴
子回复是轴对齐反驳还是换轴转移？
家庭争论跑题
争议检测 / Controversy detection
网络话题上对立立场是否稳定共存
哪些主题呈现高争议结构而非一边倒？
疫苗；城市规划
对齐 / Alignment vs 亲和 / Affiliation
对齐命题 vs 建构社会团结（常区分）
高赞是否代表命题对齐还是群体亲和？
直播弹幕「+1」
8. 索引性、语体注册与意识形态（indexicality & ideology）
术语	核心含义	可构思的问题	举一反三
索引性 / Indexicality
形式指向社会身份/语境类型（并可被再符号化）
哪些语言特征被当作「像某类人」的索引？
口音；网络缩写
语体注册 / Enregisterment
一套特征被社会认定为某语体/人格
平台是否形成可识别的评论体（句式模版）？
小红书体；贴吧体
语言意识形态 / Language ideologies
关于哪种话「正确/文明/可信」的常识政治
「理性讨论」话术是否用来剥夺对方合法性？
普通话政治；方言污名
象似化 / Iconization
把语言差异说成自然差异
是否把某种说话方式天然绑定某种道德？
阶层口音偏见
抹除 / Erasure
话语让某些行动者/因果链不可见
责任主体在语法上被背景化/删除了吗（被动/无施事）？
灾难报道；算法问责
9. 给你「举一反三」的三条总问题（跨课题通用）
指称—范畴—道德：当对象从 A 指称形式变到 B，道德结论可推导性如何变化？（把「称呼」当自变量。）
认识—证据—权威：冲突是争事实，还是争谁能定义事实（认识立场 + 证据立场）？
对齐对象到底是谁：表面在骂/夸对象，实际在向哪个观众结盟（stance triangle 第三顶点）？
